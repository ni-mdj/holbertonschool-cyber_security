# holbertonschool-cyber_security

## Overview
Entry-level cybersecurity exercises and scripts for Holberton students. The repository is organized by module, and each project folder contains short Bash utilities or report artifacts that mirror common security workflows.

## Repository layout
- `cybersecurity_basics/0x00_introduction_cybersecurity/`: intro Bash scripts (system info, password generation, hashing, SSH key creation, process checks).
- `linux_security/0x00_linux_security_basics/`: Linux security commands (logins, connections, firewall rules, auditing, packet capture, scanning).
- `network_security/0x01_passive_reconnaissance/`: passive recon scripts and a short report.
- `network_security/0x02_active_reconnaissance/`: active recon findings captured as text outputs.
- `network_security/0x04_nmap_live_hosts_discovery/`: Nmap host discovery scan variants.
- `network_security/0x05_wireshark_basics/`: Wireshark display filter basics.
- `web_application_security/0x00_web_fundamentals/`: web app fundamentals and starter tasks.
- `web_application_security/0x01_owasp_top_10/`: OWASP Top 10 exercises and notes.
- `web_application_security/0x02_burpsuite_fundamentals/`: Burp Suite setup and proxying practice.
- `web_application_security/0x03_sql_nosql_injection/`: SQL/NoSQL injection discovery tasks.

## How to use
- Make scripts executable: `chmod +x <file>`.
- Run scripts with required arguments (example: `./1-gen_password.sh 20`).
- Read each project `README.md` for scope, tooling, and file descriptions.

## Notes
- Only run scans or attacks against targets you are authorized to test.
