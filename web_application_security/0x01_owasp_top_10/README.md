# OWASP Top 10

## Description
Exercises and notes for the OWASP Top 10 module, focused on common web application risks and basic remediation awareness.

## Requirements
- All scripts are tested on Kali Linux 2023.3.
- Bash scripts start with `#!/bin/bash`.
- Files end with a newline.
- Files are executable.

## Project Files
- `0-flag.txt`: flag for task 0.
- `1-xor_decoder.sh`: decode WebSphere `{xor}` secrets.
- `2-flag.txt`: flag for task 2.
- `3-flag.txt`: flag for task 3.
- `4-vuln.txt`: task 4 answer.
