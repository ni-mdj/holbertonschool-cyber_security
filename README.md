# holbertonschool-cyber_security

Entry-level cybersecurity exercises and scripts for Holberton students. Each project directory contains small Bash utilities or report artifacts that mirror common security workflows.

## Projects
- `cybersecurity_basics/0x00_introduction_cybersecurity/`: first module scripts (system info, password generation, hashing, SSH key creation).
- `linux_security/0x00_linux_security_basics/`: Linux security commands (logins, connections, firewall rules, auditing, packet capture, scanning).
- `network_security/0x01_passive_reconnaissance/`: passive recon scripts and a short report.
- `network_security/0x02_active_reconnaissance/`: active recon findings captured as text outputs.

## How to use
- Make scripts executable: `chmod +x <file>`.
- Run scripts with required arguments (example: `./1-gen_password.sh 20`).
- Check each subdirectory `README.md` for requirements, scope, and file descriptions.
