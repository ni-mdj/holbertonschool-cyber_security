# Active Reconnaissance

## Description
Capture findings from direct interaction with a target system. This project stores answers from scans and enumeration steps as plain text artifacts.

## Learning Objectives
- Identify open ports and running services.
- Fingerprint web server technology.
- Discover input points potentially vulnerable to injection.
- Enumerate database metadata when authorized.
- Locate hidden or unlinked web directories.

## Project Files
- `0-ports.txt`: discovered open ports.
- `1-webserver.txt`: identified web server and version.
- `2-injectable.txt`: injectable endpoint path.
- `3-database.txt`: database name found during enumeration.
- `4-tables.txt`: number of tables in the database.
- `5-hidden_dir.txt`: hidden directory path.
- `100-flag.txt`, `101-flag.txt`, `102-flag.txt`: task validation flags.

## Notes
- Perform active reconnaissance only with explicit authorization and within scope.
