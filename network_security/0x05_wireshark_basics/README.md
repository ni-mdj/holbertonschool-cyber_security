# Wireshark Basics

Introductory exercises for building Wireshark display filters that isolate specific network traffic patterns.

## Learning Objectives
- Understand what Wireshark captures and how display filters work.
- Translate reconnaissance commands into filters that match generated traffic.
- Validate filters against packet details (protocols, IP headers, ports).

## Project Files
- `0-ip_scan.txt`: display filter to capture traffic generated by `nmap -sO <target>`.

## Usage
- Open Wireshark and start a capture on the correct interface.
- Run the relevant command (for this task: `nmap -sO <target>`).
- Apply the filter from the corresponding `.txt` file.

## Notes
- Always capture only traffic you are authorized to analyze.
