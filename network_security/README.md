# Network Security

## Description
Projects focused on reconnaissance techniques and evidence capture, split across passive discovery, active enumeration, host discovery, and traffic analysis.

## Projects
- `0x01_passive_reconnaissance/`: domain and DNS recon scripts plus a short report.
- `0x02_active_reconnaissance/`: active recon findings saved as text outputs.
- `0x04_nmap_live_hosts_discovery/`: Nmap live host discovery techniques.
- `0x05_wireshark_basics/`: Wireshark display filters for specific traffic.

## Usage
- Run scripts from each project directory with required arguments.
- Read each project `README.md` for scope, tooling, and file descriptions.

## Notes
- Perform reconnaissance only with explicit authorization and within scope.
