# Linux Security

Hands-on exercises focused on Linux system hardening, monitoring, and basic defensive operations using common command-line tools.

## Projects
- `0x00_linux_security_basics/`: short Bash scripts covering logins, network activity, firewall rules, auditing, and scanning.

## Usage
- Scripts are designed for Kali Linux and must be executable: `chmod +x <file>`.
- Run each script directly; refer to the project README for details and constraints.
