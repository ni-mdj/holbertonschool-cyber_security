# Linux Security

## Description
Hands-on exercises focused on Linux system hardening, monitoring, and basic defensive operations using common command-line tools.

## Projects
- `0x00_linux_security_basics/`: short Bash scripts covering logins, network activity, firewall rules, auditing, packet capture, and scanning.

## Usage
- Make scripts executable: `chmod +x <file>`.
- Run each script directly from its project directory.
- Refer to the project `README.md` for constraints and expected outputs.

## Notes
- Run commands only on systems you are authorized to test.
